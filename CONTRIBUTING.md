# Contributing

Thanks for helping with PRTG Map Studio.

## How to contribute

1. Never commit directly to `main`.
2. Create a branch from `main` (for example `fix-login-message`).
3. Make your change and test it by loading the `extension/` folder unpacked in
   Chrome (`chrome://extensions` → Developer mode → Load unpacked).
4. Open a pull request into `main` and describe what changed and why.
5. A pull request needs one approval before it can be merged.

## Please do not commit

- Real server addresses, usernames, passhashes, tokens or screenshots showing
  them. Use placeholders such as `prtg.example.com`.
- Customer or company names.
