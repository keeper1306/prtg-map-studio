Reload the Map Designer

The objects appear under the category you chose. In the Map designer, Existing PRTG objects has a Refresh object list button.

Dashboard — drag items, drag the square corner of a frame or tile to resize

Keys: arrow keys nudge the selected item (Shift = 10 px), Delete removes it, Ctrl+Z and Ctrl+Y undo and redo, Ctrl+D duplicates, Ctrl+C, Ctrl+X and Ctrl+V copy, cut and paste. Double-click a label or button to type its text; its style is open under it. Moving a frame moves what is inside it.

Stacking order: frames sit at the back, number tiles above them, then labels, buttons and status chips. Inside a group, items go in the order you added them. That is the order they will be sent to PRTG.

Paste into HTML Before

How to use: in the Map Designer add a Custom HTML item, select it, open the HTML section in Properties, and paste this into HTML Before. Save, then drag the item where you want it.

On the hover and press effects: they use a <style> block with real :hover and :active rules. Inline onmouseover handlers do not survive the HTML field — PRTG rewrites the quote characters and the handler breaks. Check hover on View Map rather than in the Map Designer, which lays its own overlay over every item.

Several buttons: the class name comes from the label text, so differently named buttons get their own rules and can be pasted into separate items without clashing. Two buttons with the same text would share one style.

Font loading: the Google Fonts link sends the viewer's IP to Google. For EU-facing or air-gapped displays, self-host the font files in \webroot\mapobjects and swap the link for an @font-face rule. If you place several items, keep the font load on one of them only and uncheck it on the rest.
